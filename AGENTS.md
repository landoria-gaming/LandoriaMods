1. Before doing any work, read and follow the entire `AGENTS.global.md` file.
2. Keep each plugin's behavior, single `README.md` used by both the repository and Thunderstore package, manifest, categories, client/server requirements, Contact section, and clear non-flat 256x256 icon synchronized. Keep licenses for public-source plugins. Changelogs are optional and may omit versions; only the ModPack changelog is required, and automation must generate its added, updated, and removed dependency entries. Keep `PluginVersion`, manifest `version_number`, `AssemblyFileVersion`, and the first three `AssemblyVersion` components identical.
3. For local runtime tests, use the authorized Valheim server at `$VALHEIM_LOCAL_DEDICATED_SERVER_PATH\Valheim dedicated server`. Before every test, copy each rebuilt required mod DLL to both the server `BepInEx\plugins` folder and `BepInEx\config\ModSentry_Required`, then copy the same DLL to the Steam client profile in `$VALHEIM_LOCAL_CLIENTS_PROFILE\profile\Steam\BepInEx\plugins` and the Xbox client profile in `$VALHEIM_LOCAL_CLIENTS_PROFILE\profile\Xbox\BepInEx\plugins`. Verify that all copies have the same hash and complete assembly version. Close both Valheim clients before replacing locked DLLs.
4. Local multiplayer tests use separate Steam and Xbox client profiles. Launch each client with its existing Steam or Xbox launcher script. Review the Steam log at `$VALHEIM_LOCAL_CLIENTS_PROFILE\profile\Steam\BepInEx\LogOutput.log`, the Xbox log at `$VALHEIM_LOCAL_CLIENTS_PROFILE\profile\Xbox\BepInEx\LogOutput.log`, and the dedicated server log at `$VALHEIM_LOCAL_DEDICATED_SERVER_PATH\Valheim dedicated server\BepInEx\LogOutput.log`. Start Normal with `start_server_normal.bat` or Hammer with `start_server_hammer.bat`, keep the server command session running, and verify the server process and log after every restart.
